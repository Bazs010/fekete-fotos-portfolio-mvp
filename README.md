# Fekete Áron – fotós portfólió MVP

## Helyi indítás

A projekt mappájában futtasd:

```bash
python3 -m http.server 8080 --directory dist
```

Ezután nyisd meg: http://localhost:8080

Az oldal három nézetet tartalmaz: Főoldal, Portfólió és Elérhetőség. Az űrlap az MVP-ben bemutató módban működik, valódi e-mailt még nem küld.
